Dans la pièce — les sélections de chacun s'appliquent pour tous :
    Commandes
    • Gâchette sur une valeur, une barre, une tour, un point : sélectionner (re-cliquer pour désélectionner)
    • Joystick en visant un volet : défiler · en visant le globe ou le nuage : tourner
    • Grip sur le globe ou le nuage : l'attraper et le faire tourner
    • Joystick gauche : marcher · droit : pivoter de 30°
    • B retour · A avancer · Y tout effacer · X revenir au centre
    • Sur PC : glisser pour regarder, ZQSD pour se déplacer (E/C monter, descendre), clic pour sélectionner, molette pour défiler, ⌫ retour
    • Sur téléphone : glisser pour regarder, joystick pour avancer, tap pour sélectionner, glisser sur un volet pour le faire défiler, Gyroscope pour regarder en bougeant le téléphone
    • Les boutons en bas emmènent vers chaque visualisation ; Suivre montre ce que voit une autre personne
